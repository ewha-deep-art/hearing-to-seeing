# design — 자막 표현

소리의 세 가지 특성을 자막의 세 가지 표현으로 옮기는 모듈들이다.

| 소리 | 표현 | 모듈 |
|------|------|------|
| 누가 말했나 (화자) | 글자 **색** | [`speaker.py`](speaker.py) |
| 언제 말했나 (단어 타이밍) | 색 **채우기** + 글자 **위아래 물결** | [`sync.py`](sync.py) |
| 얼마나 크게 말했나 (음량) | 글자 **크기** | [`volume.py`](volume.py) |

아직 확정되지 않은 값·결정은 [`docs/TODO.md`](../../../docs/TODO.md)에 따로 정리한다.

---

## 모듈 경계

- 효과 모듈(`speaker`·`sync`·`volume`)은 **자기 신호 하나만** 다룬다. 다른 효과 모듈을 import하지 않는다.
  효과를 바꾸거나 새로 만들어도 해당 모듈 안에서 끝나야 한다.
- 둘 이상이 함께 쓰는 것(폰트, 글자 크기, 단어 간격)은 [`layout.py`](layout.py)에 둔다.
- 효과 조각을 ASS Dialogue 이벤트로 조립하는 일(레이어 구성, 어떤 단어에 어떤 효과를 쓸지)은
  [`converter/ass.py`](../converter/ass.py)가 맡는다.
- 각 효과 모듈은 자기 효과를 ASS 태그 조각(`\kf`, `\move`, `\t(\fscx…)` 등)으로 돌려줄 뿐,
  Dialogue 줄 전체를 만들지 않는다.

## 자막 한 줄의 구조 (`converter/ass.py`)

화면의 자막 한 줄은 세 레이어의 Dialogue 이벤트로 그린다.

| 레이어 | 내용 |
|--------|------|
| 0. Box | 줄 전체를 불투명한 검정 박스(`BorderStyle 3`, 여백 `BOX_PAD` 6px)로. 어떤 영상 위에서도 읽히게 한다. |
| 1. Fill | 줄 전체를 흰색으로. 단어를 말하는 순간 그 단어는 숨기고 다시는 보이지 않는다. |
| 2. Pop | 단어마다 하나의 이벤트(물결 단어는 글자마다 두 개). 말한 순간부터 줄이 끝날 때까지 그 단어를 그리며 모든 효과를 싣는다. |

- 같은 글자를 두 레이어가 번갈아 그리면 글자가 떨려 보여서, Fill → Pop으로 **한 번만** 넘긴다.
- Pop 이벤트는 **줄 전체를 담고 다른 단어는 투명**하게 둔다. 그래서 libass가 Fill과 똑같은 픽셀에 단어를 놓는다.
  폰트를 직접 재서 좌표를 계산하지 않는다.
- 음량 분류에 따라 Pop의 움직임이 정해진다: loud → 확대, whisper → 축소, normal → 물결.
- 줄은 마지막 효과가 끝난 뒤 `HOLD` 0.3초 더 남는다(다음 줄이 시작되면 그 전에 끝난다).
- 캔버스는 1920×1080(`PLAY_RES`), 좌우 여백 160px, 아래 여백 60px, 화면 하단 중앙 정렬, 한 자막은 최대 두 행이다.
- 비교용 `generate_plain_ass`는 같은 줄 나눔·타이밍에 효과 없이 흰 글자만 그린다(`...`는 `…`로).
  `font`를 넘기면 Default 스타일 폰트를 바꾼다(예: 보는 PC에 설치된 "Malgun Gothic"으로 넷플릭스풍 비교본).

## 색 — `speaker.py`

화자마다 색 하나. 단어는 말하기 전에는 흰색이고, 말하는 동안 화자 색으로 채워진다(채우기는 `sync.py`).

화자 이름과 색은 **파이프라인([`pipeline.py`](../pipeline.py))이 정해** 중간 JSON의 `speaker_profiles`(`#RRGGBB`)에 넣는다. `speaker.py`는 그 값을 읽어 ASS 색(`&H00BBGGRR`)으로 바꾸는 일만 한다. 아래는 `pipeline.py`가 색을 정하는 방식이다.

- **색 공간:** OKLCH, 밝기 `LIGHTNESS` 0.75로 고정하고 hue만 바꾼다. 어떤 색이든 같은 밝기로 읽힌다.
- **배정:** `GEMINI_API_KEY`가 있으면 작품 제목 → 위키 검색 → 인물표·인물별 색 → 영상 검토(실패 시 대사)로 화자 ↔ 인물 추론 순서로 정한다.
  상세: [`knowledge/README.md`](../knowledge/README.md).
  - 인물과 매칭된 화자(신뢰도 `MIN_CONFIDENCE` 0.7 이상)는 진한 색(최대 채도의 95%)을 쓴다.
  - 매칭되지 않은 화자는 흐린 색(32%)을 쓴다. 매칭된 화자가 하나도 없으면 모두 진한 색이다.
  - 화자끼리 hue는 최소 `MIN_HUE_GAP` 40° 떨어뜨린다. 화자가 많으면 이 간격을 자동으로 줄인다.
- **폴백:** 키가 없거나 어느 단계든 실패하면 화자마다 색상환에 균등하게 배치한다.
- 결과는 `transcript.speaker_profiles`에 `#RRGGBB`로 저장되고, ASS 변환(`speaker.py`를 거쳐)과 웹 범례가 같은 값을 읽는다.
- **`speaker.py`의 폴백 팔레트:** `speaker_profiles`에 색이 없거나, 형식이 틀리거나, 흰색인 화자(예: 파이프라인 없이 로컬 JSON만 변환할 때)는
  `FALLBACK_PALETTE`(노랑·하늘·코랄·초록·보라·주황·청록)에서 차례로 색을 받는다. 흰색 그대로면 흰색 → 흰색으로 채워져 채우기가 보이지 않는다.

## 채우기와 물결 — `sync.py`

단어를 **말하는 시간**에 맞춰 움직인다.

- **말하는 시간:** 단어의 시작부터 끝까지. 다만 정렬기가 마지막 글자를 뒤 침묵까지 늘려 잡는 경우가 있어
  최대 `MAX_TRAILING_HOLD` 2초로 자른다.
- **채우기:** 흰색(스타일의 SecondaryColour)에서 화자 색(`\c`)으로 왼쪽부터 쓸어 칠한다(`\kf`).
  - loud·whisper 단어는 단어 전체를 한 번에 쓸어 칠한다.
  - 물결 단어는 말하는 시간을 글자 수로 똑같이 나눠 한 글자씩 칠한다.
  - 기다려야 할 시간은 빈 `\k`로 채운다.
- **물결 (normal 단어):** 글자들이 차례로 `WAVE_RISE_PX`(글자 크기의 8%, 64에서 5px)만큼 올라갔다 내려온다.
  - 말하는 시간을 글자 수로 나눈 칸마다 한 글자가 시작한다. 긴 단어는 한 글자씩, 짧은 단어는 겹쳐서 잔물결처럼 보인다.
  - 한 글자의 오르내림은 최소 240ms, 최대 900ms이고, 그중 45%가 올라가는 시간이다.
  - ASS는 이벤트당 `\move`를 하나만 허용하므로 글자마다 상승 이벤트(흰색)와 하강 이벤트(채우기 포함)를 하나씩 만든다.
    하강 이벤트는 줄이 끝날 때까지 남아 글자를 제자리에 둔다.
- **Fill → Pop 넘김:** 단어(물결 단어는 글자 하나하나)가 시작하는 순간 Fill에서 숨긴다. 물결 글자는 Pop 이벤트와 같은 1/100초 단위로 맞춰 틈도 겹침도 없게 한다.

## 크기 — `volume.py`

글자 크기는 고정(`layout.BASE_FONT_SIZE`)이고, 음량은 그 위의 **배율**로만 표현한다. 줄이 단어마다 다시 배치되지 않게 하기 위해서다.

- **음량 측정:** 단어 구간의 RMS를 영상 전체 단어에 대해 0–1로 정규화해 JSON에 저장한다.
- **화자 기준 음량(`relative_volumes`):** ASS로 그리기 전에 화자마다 다시 잡는다. 그 화자의 중앙값이 0.5, 5·95 백분위가 0·1이 된다.
  - 전체 정규화만 쓰면 튀는 단어 하나가 나머지를 0 쪽으로 눌러, 샘플에서는 단어의 48%가 whisper가 됐다. 이제 *그 화자에게* 튀는 단어만 loud·whisper가 된다.
  - 단어가 12개 미만인 화자는 기준이 없어 모두 0.5(normal)로 둔다. 음량이 없는 단어(`None`)도 normal이다.
  - JSON에 저장된 값은 바꾸지 않는다.
- **분류:** 화자 기준 음량이 `LOUD_THRESHOLD` 0.9 이상이면 loud, `QUIET_THRESHOLD` 0.1 이하이면 whisper, 나머지는 normal.
- **loud:** 말하는 동안 빠르게 커졌다가 → 유지 → 빠르게 100%로 돌아온다.
  - 최대 배율은 음량 0.9 → 106%, 1.0 → 118%로 직선 보간한다.
  - 커지는 시간과 돌아오는 시간은 각각 말하는 시간의 20%(최소 80ms, 최대 30%)이고, 나머지가 유지 구간이다.
  - 커질 때 자기 자리를 넓히지 않고 옆 단어 위로 겹쳐 커진다.
- **whisper:** 말하는 동안 줄어들었다가 → 유지 → 100%로 돌아온다(시간 배분은 loud와 같다).
  - 배율은 음량 0.0 → 86%, 0.1 → 92%로 직선 보간한다.
  - 줄어들면서 함께 흐려지고(`QUIET_ALPHA` 0x30, 약 19% 투명), 크기가 돌아온 뒤에도 흐린 채로 남는다.
  - Box·Fill에서는 폭을 줄이지 않는다(`width_scale`은 항상 1.0). 줄과 검정 박스는 모든 단어가 원래 크기일 때의 자리를 지키고,
    whisper 단어는 그 자리 안에서 자기 가운데를 기준으로 줄어든다.
  - 작아진 글자가 기준선에 붙지 않도록 줄어든 높이의 30%(`WHISPER_V_CENTER`)만큼 위로 올려 행 가운데에 맞춘다.
  - ASS는 이벤트당 `\move`를 하나만 허용해서, 줄어드는 이벤트와 돌아오는 이벤트 두 개로 나눈다.
- **normal:** 크기 변화 없음(물결은 `sync.py`).

## 폰트·글자 크기·간격 — `layout.py`

- **폰트:** KoPub 돋움 Bold 하나. [`fonts/KoPub Dotum Bold.ttf`](fonts/)에 번들한다.
  - ASS는 파일명이 아니라 **파일 안의 폰트 이름**으로 폰트를 찾는다. 그래서 스타일은 `KoPubDotum Bold` + Bold 플래그로 지정한다.
    이름이 틀리면 에러 없이 다른 폰트로 그려진다.
  - 이름과 파일이 맞는지는 [`tests/test_layout.py`](../../../tests/test_layout.py)가 확인한다.
- **어디서나 같은 폰트:** 프리뷰 렌더러(`render.py`)는 이 폴더를 libass `fontsdir`로 넘긴다.
  웹 플레이어(JASSUB)는 같은 파일을 `/api/subtitle-font`로 받는다.
  - 폰트를 바꾸면 `layout.py`의 `FONT_FILE`·`FONT_NAME`, [`watch.js`](../../web/static/watch.js)의 `SUBTITLE_FONT_NAME`을 함께 바꾼다.
- **글자 크기:** `BASE_FONT_SIZE` 64.
- **단어 간격:**
  - 모든 띄어쓰기를 원래 폭의 92%(`SPACE_TIGHTNESS`)로 좁힌다.
  - 띄어쓰기는 양옆 단어의 폭 배율(`width_scale`) 중 작은 쪽을 따르지만, 지금은 모든 단어가 폭을 그대로 두므로 항상 92%다.
